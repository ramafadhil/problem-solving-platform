## 📌 Tentang Proyek

**Unravel** adalah platform pembelajaran berbasis web yang memanfaatkan pendekatan *E-Scaffolding* dan strategi *Question Chains* untuk membantu mahasiswa melatih kemampuan pemecahan masalah (*problem solving*) pada studi kasus kompleks (*ill-structured problems*). 

Dengan memecah proses analisis masalah ke dalam 4 pilar utama (**Tujuan, Stakeholder, Masalah, dan Solusi**), Unravel membantu pengguna berpikir lebih sistematis sekaligus mereduksi kecenderungan *transformation error* dan beban kognitif saat belajar.

---

## ✨ Fitur Utama

- **🎮 Mode Belajar (Learning Mode):** Pengerjaan studi kasus berbasis *gamification* dengan alur linier, mekanisme *drag-and-drop* blok logika ke pilar analisis, serta sistem pembukaan level (*level unlock*).
- **💬 Mode Diskusi (Discuss Mode):** Forum kolaboratif untuk berbagi perspektif studi kasus, mempublikasikan lembar kerja analisis, serta memberikan reaksi (*like/dislike*) dan balasan komentar.
- **✍️ Kontribusi Studi Kasus:** Fitur yang memungkinkan pengguna membuat, menerbitkan, dan membagikan studi kasus baru ke dalam ekosistem platform.
- **🏆 Gamifikasi & Papan Peringkat:** Sistem poin, statistik keterlibatan, kalkulasi *streak* harian, dan *leaderboard* pengguna.
- **👤 Profil & Pengaturan Privasi:** Manajemen akun dengan dukungan visibilitas profil fleksibel (Mode Publik atau Anonim) untuk kenyamanan saat berdiskusi.

## 🛠️ Stack Teknologi

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Bahasa Pemrograman:** TypeScript
- **Styling & UI:** Tailwind CSS
- **Interaktivitas & Animasi:** Lottie Animation (Adobe After Effects)
- **Backend API:** Go / Golang *(repository terpisah)*
- **Database:** PostgreSQL

## 🚀 Panduan Memulai (Getting Started)

### Prasyarat

Pastikan Anda telah menginstal lingkungan pengembangan berikut:
- **Node.js**: versi 18.x atau lebih baru
- **Package Manager**: `npm`, `yarn`, `pnpm`, atau `bun`

### Langkah Instalasi

1. **Clone repositori ini:**
   ```bash
   git clone [https://github.com/ramafadhil/problem-solving-platform.git](https://github.com/ramafadhil/problem-solving-platform.git)
   cd problem-solving-platform
   ```

2. **Instal dependensi proyek:**
   ```bash
   npm install
   # atau
   yarn install
   # atau
   pnpm install
   # atau
   bun install
   ```

3. **Jalankan server pengembangan lokal:**
   ```bash
   npm run dev
   # atau
   yarn dev
   # atau
   pnpm dev
   # atau
   bun dev
   ```

4. **Buka di Peramban Web:**
   Buka [http://localhost:3000](http://localhost:3000) pada browser Anda untuk melihat hasilnya secara lokal.
